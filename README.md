# hxyfront-62006 珠宝镶嵌宝石分拣

源提示词编号：8

我需要一个面向珠宝镶嵌工作室的宝石分拣前端系统，可以记录宝石编号、种类、形状、克拉重量、尺寸、净度、颜色、切工、镶嵌位置和分拣状态。页面需要有分拣批次、尺寸筛选、镶嵌位置示意图、缺陷备注和按订单查看的宝石清单。

## 独占分配流程

1. **尺寸范围挑石**：从 0–2 / 2–5 / 5–8 / 8mm+ 四个尺寸范围中选一个，列表只显示待镶嵌宝石（已分配的自动移出），勾选即视为同一批次，支持全选。
2. **指定订单与镶嵌位**：选择订单后，在镶嵌位示意图（主石居中、其余位置环绕）或下拉框中指定镶嵌位，并可填写整批共用的缺陷备注。
3. **独占提交**：
   - 尺寸未选、批次为空或镶嵌位为空时一律拒绝提交；
   - 目标镶嵌位已被其他批次占用时，**整批宝石都不写入**，页面顶部保留当前订单与冲突位置（含占用批次、宝石、时间）的红色提示，勾选与备注不清空，改选空闲位置即可重试；
   - 成功后生成连续批次号（PC-0001…）并清空勾选/位置/备注。
4. **订单清单汇总**：按订单展示已分配颗数、待镶嵌颗数（共需 − 已分配）、每个镶嵌位的占用情况与批次明细。
5. **断点续处理**：分配记录与当前草稿（尺寸范围、勾选、订单、位置、备注）均存于 localStorage，关闭页面再打开可继续。
